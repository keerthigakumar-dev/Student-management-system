# Student Management System

## 📌 Description
This is a Java-based application developed to manage student records efficiently. The system allows users to store, view, and manage student information.

## 🛠️ Technologies Used
- Java
- OOPS Concepts

## 📂 Features
- Add new student details
- View student records
- Manage student performance
- Simple and user-friendly structure

## 📁 Project Structure
- Mainclass.java
- Student.java
- Studentservice.java
- Performancestudent.java

## 🚀 How to Run
1. Open the project in any Java IDE (Eclipse/IntelliJ)
2. Compile all Java files
3. Run the Mainclass.java file
